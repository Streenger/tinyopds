# TinyOPDS v3.22.6 (Streenger Edition) - Release Notes

Обновление форка после 3.17.0: доработки нормализатора библиотеки, выборочный перенос исправлений upstream до 3.23 (`sensboston/tinyopds`) и проверка обновлений по релизам этого форка. Полное слияние upstream не выполнялось: изменения, затрагивающие сканер, базу и правила доступа, отложены отдельно.

---

## Основные изменения / Highlights

### 1. Нормализатор библиотеки
- **Папка на каждый сборник**: многокнижный архив (например, `fb2-000024-030559.zip`) раскладывается в папку с тем же именем без `.zip`, каждая книга упаковывается в собственный ZIP.
- **Поархивное удаление исходника**: исходный архив удаляется сразу после того, как все его книги записаны и сброшены на диск, событие пишется в лог до перехода к следующему архиву. Если хоть одну книгу записать или сбросить не удалось, исходник остаётся.
- **Возобновление после прерывания**: уже записанные книги пропускаются без копий « (2)»; совпадение определяется по имени, размеру и CRC32 из заголовков ZIP, без распаковки. Недописанный ZIP перезаписывается, другая книга с тем же именем получает следующий свободный суффикс. В лог добавлено поле `skippedExisting`.
- **Один сброс на диск на архив** вместо сброса после каждой книги — при той же гарантии перед удалением исходника.
- Ранее (после 3.17.0): индекс `normalized.index`, атомарная перезапись архивов, восстановление вложенности тегов FB2, запись ID и дат документа, таблица псевдонимов жанров, защита украинского и двуязычного текста в санитайзере, ускорение сканирования.

### 2. Перенесено из upstream 3.18–3.23
- **Веб-читалка (3.22–3.23)**: сноски FB2/EPUB во всплывающем окне или нижней панели на телефоне; надстрочный/подстрочный текст, зачёркивание и код FB2; исправлено открытие EPUB с горизонтальной линией; позиция чтения запоминается для последних 300 книг; язык переносов следует за переводом страницы.
- **Обложки**: адреса обложек с меткой версии (`?v=`) — после замены книги новой версией не показывается старая обложка из кэша; повторное извлечение потерянной обложки; размер до 480×800; разбор путей обложек EPUB.
- **Иконки сайта для телефонов**: `/favicon.ico` (16/32/48), `/icon-192.png`, `/apple-touch-icon.png`; отдаются без входа (только эти точные адреса).
- **Каталог и поиск**: авторы и переводчики в порядке книги; фонетические совпадения авторов не засоряют поиск по названию; язык интерфейса и описаний в HTML.
- **Склонения**: правила загружаются и в CLI, исправлены формы после предлогов.
- **Окно и трей**: восстановление размера и положения после смены экрана, поднятие окна по клику на значок.

### 3. Проверка обновлений
- Проверяются релизы **Streenger/tinyopds**, а не оригинального проекта; номер версии из тега разбирается полностью (`v3.22.6`), поэтому патч-релизы форка распознаются.

### Отложено (не входит в релиз)
Пакетная запись и счётчики сканера 3.18, новый алгоритм дублей, Watcher, загрузка книг из браузера 3.19, несколько серий 3.20, автоустановщик обновлений, поиск ё/е и новая авторизация 3.21, доступ к обложкам по IP, Docker.

### Проверка
Сборка GUI и CLI (.NET Framework 4.8, Release) без ошибок; 20 проверок раскладки нормализатора, 25 проверок перенесённых исправлений, 8 проверок источника обновлений, 3 SQL-теста и тест языка читалки.

## English Version

**TinyOPDS v3.22.6 (Streenger Edition)**

- **Library normalizer**: each multi-book archive is split into a folder named after it, one ZIP per book; the source is deleted right after all its books are written and flushed, and logged before the next archive; a resumed run skips books already written (name, size and CRC32 from the ZIP headers, no decompression) instead of creating " (2)" copies; one disk flush per archive.
- **Selective upstream 3.18–3.23 imports**: web reader notes and reading position, sup/sub/strikethrough/code, versioned cover URLs, cover cache and EPUB cover path fixes, phone site icons, author order, search and language fixes, CLI plural rules, window/tray restoration.
- **Update check** now uses the releases of Streenger/tinyopds and full version tags.
- Deferred: scanner batch writer, new duplicate detection, watcher, web uploads, multiple series, auto-installer, ё/е search and new auth, Docker.
